# Guriのライブラリ配置

このディレクトリはリポジトリ内にSchemeライブラリを置く場合の配置例です。
暗黙の検索先ではなく、利用する場合は検索パスへ明示指定します。
ユーザーのスクリプトとライブラリは任意の場所に配置できます。
既存の `examples/` はサンプル置き場として維持します。

内部Runtimeの10標準ライブラリはGo実装と公開束縛表としてバイナリへ組み込みます。
外部ライブラリは、明示指定、`GURI_LOAD_PATH`、インストール時のsite／同梱ディレクトリの順に検索します。
インストール手順と公開CLIへの指定方法は#67で接続します。

名前の対応、includeの基準、標準ライブラリと初期化の規則は
[ライブラリ仕様](../docs/wiki/Libraries.md)を参照してください。
