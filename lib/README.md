# Guriのユーザーライブラリ

ライブラリの既定検索先は、実行時の作業ディレクトリにある `lib/` です。
たとえば `(myapp util)` の定義は `lib/myapp/util.sld` に配置します。
既存の `examples/` はサンプル置き場として維持します。

内部Runtimeでは検索先を明示指定でき、指定したディレクトリを順に検索します。
標準ライブラリは処理系に組み込んだ公開束縛表から提供します。
公開CLIと公開Go APIの接続は後続の移行タスクです。

名前の特殊文字、includeの基準、対応する標準ライブラリと初期化の規則は
[ライブラリ仕様](../docs/wiki/Libraries.md)を参照してください。
